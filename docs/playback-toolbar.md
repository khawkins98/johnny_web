# Playback toolbar and Captain’s log

Start Classic or Enhanced to show the bottom toolbar. Its original pixel icons and nautical wood/parchment surfaces take layout inspiration from the adventure/RPG screenshots supplied by the user, including Flight of the Amazon Queen. No reference-game artwork is included. The icons and surface tiles were created with Google Antigravity’s noninteractive CLI, inspected locally and integrated as editable SVG pixel geometry; see [asset provenance and palette](../src/games/johnny/ui/deck-icons/README.md).

The toolbar offers sound, playback speed (0.5×, 1×, 2×, 4×), Timeline, Picture, Options, fullscreen, Log and Hide. Sound and Options use the existing settings; Picture opens the existing optional CRT controls. Timeline opens the full story browser and scene-flow view. These controls do not change the Classic/Enhanced profile automatically, other than changes to individual settings that already mark an experience Custom.

**Log** opens a nonmodal sidebar on the right. Story position, visited story-day marks, unique gags visited and visible playback time appear above the current gag and visit-position meter. Statistics last for this playback session and reset when returning to the title. A visit is one planned batch; a gag preview is labeled separately. Visited gags count unique catalogue selections, including previews; idle POSE/STAND fillers do not count. These are not completion achievements or a claim that every animation in a gag was watched.

The lower section browses story day, time-of-day band and eligible gags. **Visit this day** starts a visit anchored by that day’s key scene; arrows visit adjacent days. **Play gag** previews exactly the chosen gag, and the neighboring arrows browse that day/band’s eligible gag list. **Return to live story** leaves preview/browsing and resumes the normal controller. Browsing choices remain stable as the live story updates. Requirements such as forced night/high tide remain owned by the existing story controller.

On screens wider than 900 CSS pixels, opening the log reserves space beside the game. The toolbar reserves space below it. Native/Integer retain their original scale semantics, so they may exceed the available area on a small screen; Freeform fits the remaining area and Stretch uses that area. On narrower screens the log overlays the right side and scrolls internally, leaving the toolbar reachable. Closing the log restores the game area. Hiding the toolbar releases all reserved space. The CRT compositor follows the resulting canvas rectangle; interface controls stay outside the effect.

`H` hides/restores the toolbar, including when a toolbar button has focus. A small corner button provides a pointer/touch route back. Hidden controls are inert. `Esc` closes the log and returns focus to its toggle; modal dialogs take precedence. Existing `S`, `T`, `R`, arrow-key animation stepping/speed and `F` shortcuts remain. Text/select controls keep their own keyboard behavior. Fullscreen failures are reported without interrupting playback.

Implementation: [enhanced.mjs](../src/games/johnny/ui/enhanced.mjs) retains its existing setup hook name for compatibility; [playback-deck.css](../src/games/johnny/ui/playback-deck.css) provides the chrome. Bottle passes the existing settings, timeline and debug-run coordinator into the hook for both experiences. Navigation requests use that coordinator’s atomic runtime/walk/audio handoff; this UI does not create another playback loop. Settings owns available-area scaling and the normal CRT presentation boundary.

The UI’s rAF reads runtime speed and updates visible values at most four times per second. Gag/day state comes from the existing subscription, with cleanup on return to title. Visible playback time excludes hidden-tab intervals. No session stats are written to an account or browser storage.

Validation and captures are recorded on issue #81 and the UI draft PR. Synthetic/unit checks cover log visibility/inert cleanup, coordinator requests, selection stability, unique counts and modal/keyboard behavior. Actual Johnny browser checks exercise day jumps, exact gag previews, live return, sound/speed, desktop geometry, mobile overflow, and VGA output alignment when the log opens/closes. Proprietary game captures remain ignored locally and attached to GitHub rather than committed.
