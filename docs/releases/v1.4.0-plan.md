# v1.4.0 — Island TV: release plan

Status: proposed minor release, unpublished. Latest published release: v1.3.0. `package.json` remains at 1.3.0 until release preparation is ready. The UI/CRT features are still in draft PRs.

## Scope and merge sequence

1. [#84 — presentation research](https://github.com/khawkins98/johnny_web/pull/84), based on main.
2. [#85 — optional CRT implementation](https://github.com/khawkins98/johnny_web/pull/85), currently based on #84's branch.
3. [#86 — Island TV and playback UI](https://github.com/khawkins98/johnny_web/pull/86), currently based on #85's branch.

Finish review and merge in that order. Retarget each remaining PR to main after its parent lands, resolve any resulting conflicts and verify the final diff. CI currently runs for PRs targeting main and pushes to main; a green local run on the stacked branch is not evidence of final-main CI.

Use the [Unreleased changelog](../../CHANGELOG.md) as the source of release notes. Include the selected day/time playback correction already landed in #83. No engine-faithfulness expansion is claimed beyond the previously documented evidence.

- Latest targeted UI/CRT suite after Balanced/Stretch became defaults: 93 passed; production build passed.
- Isolated actual-game browser checks at desktop/mobile sizes, including 1940×1200, 1440×1000, 1024×768 and 390×844: launch/return-to-title, native 640×480 buffers, real CRT output, saved preference retention, pause/speed/dials, TV hide/restore, Log/gag navigation, clock saving and progressive disclosure.
- Options keyboard focus wrapping and WCAG2A/AA audit: zero reported violations; heading text-shadow contrast also reviewed visually.
- README screenshot supplied by the user, with Log closed to show hardware controls; original-game art credit retained. Original game archives are not release assets.
