## Validation and red-team record

- First UI review identified two keyboard defects: Space on the focused TV-restore button paused instead of activating it, and Settings' R shortcut could restart behind an open Timeline. Both were fixed with regression tests and verified in an isolated browser.
- Second UI red-team pass found no further verified actionable issue; 55 focused tests passed. A separate CRT/playback/licensing review found no additional blocker and confirmed the GPL Guest shaders remain lab-only.
- Full serial suite on the release-preparation branch: **897 passed, two skipped**. Frozen-lockfile install and production Pages-base build passed. The two skips are the existing Linux-only ffmpeg alpha renderer cases on this macOS host.
- Targeted UI/CRT suite: **95 passed** after the fixes. The synthetic WebGL lifecycle checker passed native-buffer preservation, no-WebGL fallback, resize, bypass, context loss/restoration, page lifecycle and failure cleanup/retry. Standalone lab scaling tests passed.
- Actual-game isolated Chromium checks covered launch/return-to-title, pause/resume, dial rotation, speed, saved preferences, day/gag navigation, clock saving, modal focus and the two keyboard fixes. Desktop, mobile and DPR 1, 1.25 and 2 captures were inspected.
- The latest README screenshot is the exact user-supplied night scene, with Log closed to show the controls and original-game art credit retained. Original game archives are not release assets.

## Validation limits

Current Firefox/Safari and sustained playback on a modest physical device were not tested for this release. The browser evidence is Chromium; emulated DPR/mobile checks do not establish performance on physical devices. These remain follow-up validation, and the published notes disclose this limit.
